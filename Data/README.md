# Data

De oorspronkelijke dataset wordt niet in de repository opgenomen.

## Bron

De les- en aanwezigheidsdata werd vanuit SQL geëxporteerd naar:

`dataset_aanwezigheden.csv`

De notebook verrijkt deze data met historische weergegevens via de Open-Meteo API.

## Mappen

- `raw/`: onbewerkte data
- `processed/`: eventueel later opgeslagen opgeschoonde of getransformeerde data

Controleer altijd of de dataset persoonsgegevens, interne schoolgegevens of andere gevoelige informatie bevat voordat data publiek wordt gemaakt.
